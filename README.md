# Bryce Gilmore — Portfolio

A personal portfolio site built for the Market-Facing Portfolio final project, targeting roles in sports business and analytics.

**Live site:** https://brycegilmore.github.io/portfolio/

## What's here

- **About** — background as a Wake Forest MSBA candidate (Sports Analytics Concentration) and NCAA Division I distance runner
- **Video** — a short recorded introduction
- **Resume** — two labeled versions, each viewable and downloadable as a PDF: **Sports Analytics** (shown inline) and **Business Analytics**
- **Work** — three academic research projects (econometrics, regression modeling, applied statistics), each linking to the full writeup
- **Market View** — a short take on where sports analytics is heading
- **Contact** — email and LinkedIn

## Built with

Plain HTML, CSS, and JavaScript — no framework or build step. Includes a mobile/desktop view toggle built with CSS container queries.

## Structure

```
index.html          Page content
styles.css           Styling
script.js             Nav toggle, scroll reveal, view toggle
assets/
  img/                Headshot
  resume/              Resume PDFs (Sports Analytics + Business Analytics)
  video/                Intro video
  projects/             Project write-ups (PDF/XLSX)
```
